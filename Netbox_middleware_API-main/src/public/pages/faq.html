FAQ

Perguntas Frequentes

Q: O que é o NetBox Report Dashboard?

R: É uma plataforma web responsável por importar, organizar e apresentar os dados do Netbox através de gráficos, indicadores e relatórios.


Q: O sistema altera informações no Netbox?

R: Dashboard realiza apenas leitura das informações disponibilizadas pela API do NetBox e as armazena em um banco de dados para consulta e geração de relatórios.


Q: Como faço para conectar ao NetBox?

R: Para conectar ao NetBox, você precisa fornecer o endereço do servidor, porta, usuário e senha corretos. Certifique-se de que as informações estejam corretas e que você tenha acesso à rede onde o NetBox está hospedado.


Q: O que devo fazer se encontrar um erro ao tentar acessar o NetBox?

R: Se você encontrar um erro ao tentar acessar o NetBox, verifique se as informações de conexão estão corretas. Além disso, certifique-se de que o servidor do NetBox esteja em execução e acessível. Se o problema persistir, entre em contato com o suporte técnico.


Q: Como eu configuro o Banco de Dados?

R: Para configurar o Banco de Dados, você precisa acessar a página de configurações e preencher os campos correspondentes com as informações do seu banco de dados. Certifique-se de fornecer o nome correto do banco de dados exibido no status.


Q: Onde posso encontrar as informações depois da sincronização?

R: Depois da sincronização é possível verificar através do banco de dados conectado, onde será utilizado para geração de graficos visual em Dashboard. É possível verificar os dados disponíveis gerando a tabela após clicar em "Exibir Logs" na aba Status, caso o problema persista, entrar em contato com o suporte técnico.


Os dados são atualizados automaticamente?

R: Sim, os dados são atualizados automaticamente se a sincronização automática com o NetBox está ligada.


Q: O que é a sincronização automática?

R: A sincronização automática é um recurso que permite que o sistema atualize os dados do NetBox automaticamente em intervalos regulares, sem a necessidade de intervenção manual. Isso garante que as informações exibidas no Dashboard estejam sempre atualizadas.


Q: Posso exportar os relatórios gerados pelo Dashboard?

R: Sim, o Dashboard oferece opções para exportar os relatórios em PDF, permitindo que você compartilhe ou armazene os relatórios conforme necessário.


Q:Os gráficos são atualizados automaticamente?

R: Sim, os gráficos são atualizados automaticamente conforme os dados são sincronizados com o NetBox.


Q:Quais bancos de dados são utilizados?

R: O NetBox Report Dashboard utiliza o PostgreSQL como banco de dados para armazenar as informações sincronizadas com o NetBox.


Q: Os gráficos não geram após a sincronização.

R: O problema mais comum, é a falta de dados necessários para que o sistema possa gerar os gráficos. Verifique se após a sincronização, as informações estão disponíveis e completos no banco de dados conectado.
